# World map data attribution

`apps/dashboard/public/world-map.json` contains simplified screen coordinates derived from Natural Earth 1:110m country geometry. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson (downloaded2026-09-30). Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/.

Country geometry is a visualization aid, not a position on disputed boundaries. The map uses recorded event country codes; it does not perform geolocation or invent missing locations. Country rankings come from the overview distribution; unmapped/no-data areas use the neutral fill. Country-list controls provide a keyboard alternative to pointer selection.
